Πολιτική απορρήτουPrivacy policy

Τελευταία ενημέρωση: 27 Οκτωβρίου 2026Last updated: 27 October 2026

Με λίγα λόγια:In short: Το HubBlocks δεν συλλέγει, δεν αποθηκεύει και δεν μοιράζεται προσωπικά δεδομένα. Δεν υπάρχουν λογαριασμοί, διαφημίσεις ή εργαλεία παρακολούθησης. Τα projects μένουν στη συσκευή σας. HubBlocks does not collect, store or share personal data. There are no accounts, ads or tracking tools. Projects stay on your device.

Ποιος είναι υπεύθυνοςWho is responsible

Το HubBlocks είναι ανεξάρτητο, δωρεάν έργο ανοιχτού κώδικα του Κωνσταντίνου Μπεζαΐτη. Για ερωτήσεις: GitHub Issues. HubBlocks is an independent, free, open-source project by Konstantinos Bezaitis. For questions: GitHub Issues.

Τι δεν συλλέγουμεWhat we don't collect

  • Δεν υπάρχουν λογαριασμοί χρηστών, ονόματα ή email.There are no user accounts, names or emails.
  • Δεν χρησιμοποιούμε cookies, analytics ή διαφημίσεις.We use no cookies, analytics or advertising.
  • Τα projects των μαθητών δεν ανεβαίνουν πουθενά. Αποθηκεύονται μόνο όταν ο χρήστης κατεβάσει ένα αρχείο .sb3 στη συσκευή του.Students' projects are not uploaded anywhere. They are only saved when the user downloads an .sb3 file to their device.

Τι μένει στη συσκευή σαςWhat stays on your device

  • Ρυθμίσεις (π.χ. γλώσσα) αποθηκεύονται τοπικά στον browser και δεν στέλνονται πουθενά.Settings (e.g. language) are stored locally in the browser and are not sent anywhere.
  • Αρχεία της εφαρμογής αποθηκεύονται στη συσκευή ώστε να λειτουργεί χωρίς internet. Διαγράφονται με την απεγκατάσταση της εφαρμογής ή με τη διαγραφή των δεδομένων του ιστότοπου.App files are stored on the device so it works offline. They are removed by uninstalling the app or clearing the site's data.
  • Bluetooth: χρησιμοποιείται μόνο για την επικοινωνία με το hub που επιλέγει ο χρήστης. Η επικοινωνία γίνεται απευθείας ανάμεσα στη συσκευή και στο hub· καμία πληροφορία δεν στέλνεται στο internet.Bluetooth is used only to communicate with the hub the user selects. Communication happens directly between the device and the hub; no information is sent to the internet.

Υπηρεσίες τρίτωνThird-party services

  • GitHub Pages φιλοξενεί τον ιστότοπο και την εφαρμογή. Όπως κάθε server, το GitHub μπορεί να καταγράφει τεχνικά στοιχεία των επισκέψεων (π.χ. διεύθυνση IP). Δείτε τη δήλωση απορρήτου του GitHub.GitHub Pages hosts the website and the app. Like any server, GitHub may log technical visit data (e.g. IP address). See the GitHub privacy statement.
  • Οι βιβλιοθήκες του Scratch (έτοιμα sprites, ήχοι, σκηνικά) φορτώνονται από τους servers του TurboWarp μόνο όταν ο χρήστης τις ανοίξει. Δείτε την πολιτική απορρήτου του TurboWarp.The Scratch libraries (ready-made sprites, sounds, backdrops) are loaded from TurboWarp's servers only when the user opens them. See the TurboWarp privacy policy.

ΠαιδιάChildren

Το HubBlocks είναι σχεδιασμένο για χρήση στην τάξη, και από παιδιά, υπό την επίβλεψη εκπαιδευτικού ή γονέα. Επειδή δεν ζητά και δεν συλλέγει κανένα προσωπικό στοιχείο, δεν συλλέγει ούτε δεδομένα παιδιών. HubBlocks is designed for classroom use, including by children, under the supervision of a teacher or parent. Because it requests and collects no personal information, it collects no children's data either.
